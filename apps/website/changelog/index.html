Winter has a new home

8 November 2026

A new home. A bolder winter.

The website, playground, documentation and private dashboard now live at winter.fluri.xyz, with vivid purple styling and a redesigned live workshop. Fluri Themes has its own collection and founder homepage. Existing package names, APIs and dashboard access remain supported.

A framework independent snow engine, an interactive workshop, and the controls to make the forecast yours.

Snow with somewhere to land

  • Surface-local accumulation with uneven packing profiles and rounded shoulders.
  • Supported movement, responsive geometry, clipping, and sampled occlusion.
  • Wind, granular flow, displaced snow, and transfer to lower surfaces.

A little room to play

  • Pointer brushing, snowballs, snowmen, and a snowplough for designated routes.
  • Ten presets and a live playground with configuration export.
  • Optional, explicitly placed Christmas decorations.

Considered integrations

  • TypeScript APIs, runtime configuration validation, and an optional React adapter.
  • Reduced-motion policy, hidden-tab suspension, and complete lifecycle cleanup.
  • Adaptive particle density, late-frame quality response, and bounded overflow.

Install the core and optional React adapter from npm, or download versioned archives from the documentation page.
