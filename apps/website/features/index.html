A winter effect should feel like part of your website. Here is how Fluri makes room for the snow without taking over the interface.

SURFACES & PHYSICS

It settles in.
Then goes along.

Fluri keeps snow in each surface’s local coordinates. Deposits follow translation, supported rotation, scrolling, and responsive geometry. A fast movement can shake some loose.

Uneven packing, rounded shoulders, wind, and granular flow shape each pile. Snow displaced from one supported edge can fall onto the next.

THE DETAILS YOU CAN WORK WITH

Small moments.
Useful controls.

Choose where winter lands.

Automatic discovery for supported edges, or explicit attributes and JavaScript registration for predictable integration. Per-surface material, depth, and layer controls.

Make it interactive.

Brushing, gathering, throwing, snowballs, snowmen, and a tiny snowplough. Turn individual interactions on or off to suit your page.

Give it a forecast.

Ten presets, runtime intensity controls, variable wind, gusts, flake styles, accumulation, and optional custom textures.

Set a sensible budget.

Adaptive ambient density, late-frame response, capped pixel ratio, bounded overflow particles, and inspectable runtime metrics.

Respect the person visiting.

Reduced-motion policy, hidden-tab suspension, optional pause controls, and complete teardown of listeners, observers, and overlays.

Build on a typed API.

A framework independent controller, a React adapter, lifecycle events, runtime updates, and a plugin API for your own ideas.

A LITTLE EXTRA FOR THE HOLIDAYS

Set the lights.
Keep the choice.

The optional Christmas module adds warm lights, garlands, ornaments, frost, icicles, gifts, wreaths, candy canes, and sparkles to the surfaces you label.

Decorations are deliberate. Add a data attribute where each belongs, and leave the rest of your page alone.

BUILT FOR THE BROWSER WE HAVE

Thoughtful effects.
Honest boundaries.

Fluri approximates supported DOM geometry and painting order. It does not reproduce the browser compositor or a three-dimensional snow simulation.

Complex perspective transforms, arbitrary masks, closed shadow-root internals, cross-origin iframe contents, and some top-layer behavior have limits. Explicit surfaces give you more predictable results.
